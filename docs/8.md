# Routing in UI5

**Routing** is the mechanism that:

- Maps a **URL hash** to a **View**
- Loads and displays that view automatically
- Enables **browser back/forward navigation**

## Routing Architecture Overview

```
URL Hash
   ↓
Router
   ↓
Route
   ↓
Target
   ↓
View loaded into control (App / NavContainer)
```

## Routing Configuration (manifest.json)

### 1. Routes

Routes define **URL patterns**.

```json
"routes": [
  {
    "pattern": "",
    "name": "home",
    "target": "Home"
  },
  {
    "pattern": "detail/{id}",
    "name": "detail",
    "target": "Detail"
  }
]

```

Pattern Types

| Pattern              | Meaning             |
| -------------------- | ------------------- |
| ""                   | Default route       |
| "detail/{id}"        | Mandatory parameter |
| "detail/:id:"        | Optional parameter  |
| "detail/{id}/{type}" | Multiple parameters |

### 2. Targets

Targets define **what view loads**.

```json
"targets": {
  "Home": {
    "name": "Home",
    "id": "Home"
  },
  "Detail": {
    "name": "Detail",
    "id": "Detail"
  }
}

```

## Navigation in Controllers

### 1. Get Router Instance

```jsx
var oRouter = this.getOwnerComponent().getRouter();
```

### 2. Navigate to a Route

```jsx
oRouter.navTo("detail", {
  id: "1001",
});
```

This updates the URL to:

```
#/detail/1001
```

### 3. Replace History (No Back Navigation)

```jsx
oRouter.navTo("home", {}, true);
```

## Reading Route Parameters

In the **target controller**, attach to route:

```jsx
onInit: function () {
  var oRouter = this.getOwnerComponent().getRouter();
  oRouter.getRoute("detail").attachPatternMatched(this._onRouteMatched, this);
},

_onRouteMatched: function (oEvent) {
  var sId = oEvent.getParameter("arguments").id;
}
```
