# Binding Concept in SAP Ui5

In **SAPUI5**, _data binding_ connects UI controls to data models so the UI stays in sync with the underlying data.

## 1. Property Binding

**Purpose:**

Binds a _single property_ of a control to a _single value_ in the model.

**Typical use cases:**

- Text of a label
- Value of an input field
- Visibility or enabled state

**Example (XML View):**

```xml
<Input value="{/user/name}" />
<Text text="{i18n>appTitle}" />
```

**Example (JS):**

```jsx
oInput.bindValue("/user/name");
```

**Key points:**

- One-to-one binding
- Automatically updates UI when model data changes
- Can be **OneWay**, **TwoWay**, or **OneTime**

## 2. Aggregation Binding (List Binding)

**Purpose:**

Binds a _collection (array)_ from the model to an _aggregation_ of a control (like items, rows, cells).

**Typical use cases:**

- Lists
- Tables
- ComboBoxes
- Select controls

**Example (XML View):**

```xml
<List items="{/Products}">
  <StandardListItem
    title="{Name}"
    description="{Category}" />
</List>
```

**Example (JS):**

```jsx
oList.bindItems({
  path: "/Products",
  template: oTemplate,
});
```

**Key points:**

- One-to-many binding
- Template defines how each item is rendered
- Supports sorting, filtering, and grouping

## 3. Element Binding (Context Binding)

**Purpose:**

Binds a control (and its children) to a _single object_ in the model.

**Typical use cases:**

- Detail pages
- Forms
- Object pages

**Example (XML View):**

```xml
<Panel binding="{/Product/0}">
  <Text text="{Name}" />
  <Text text="{Price}" />
</Panel>
```

**Example (JS):**

```jsx
oPanel.bindElement("/Product/0");
```

**Key points:**

- Sets a binding context
- Child controls bind relative to that context
- Reduces repetition of binding paths

## 4. Expression Binding

**Purpose:**

Allows simple calculations and logic directly in XML.

**Typical use cases:**

- Conditional visibility
- Formatting text
- Simple boolean logic

**Example:**

```xml
<Text text="{= ${price} > 100 ? 'Expensive' : 'Affordable' }" />
```

**Key points:**

- No formatter function needed
- Best for simple logic only
- Read-only

# Binding Modes in SAPUI5

A **binding mode** defines the **direction of data flow** between the **model** and the **UI control**.

SAPUI5 supports **three binding modes**.

## 1. OneWay Binding

**Data flow:**

**Model → UI**

**Description:**

- UI is updated when model data changes
- User changes in UI **do NOT** update the model

**Common use cases:**

- Labels
- Text fields (read-only)
- Status displays

**Example:**

```xml
<Text text="{path: '/status', mode: 'OneWay'}" />
```

## 2. TwoWay Binding (Default for most models)

**Data flow:**

**Model ↔ UI**

**Description:**

- UI changes update the model automatically
- Model changes update the UI automatically

**Common use cases:**

- Input fields
- Forms
- Editable tables

**Example:**

```xml
<Input value="{path: '/userName', mode: 'TwoWay'}" />
```

**Setting default mode:**

```jsx
oModel.setDefaultBindingMode(sap.ui.model.BindingMode.TwoWay);
```

**Important:**

- JSONModel → default is **TwoWay**
- ODataModel → default is **OneWay**

## 3. OneTime Binding

**Data flow:**

**Model → UI (once only)**

**Description:**

- Value is read only once when binding is created
- Later model changes are ignored

**Common use cases:**

- Static configuration values
- Initial texts
- Performance optimization

**Example:**

```xml
<Text text="{path: '/appVersion', mode: 'OneTime'}" />
```
