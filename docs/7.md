# Event

An **event** happens when a user:

- clicks a button
- types in an input
- selects a list item
- changes a value
- presses Enter

UI5 **control fires an event**

**Controller function handles it**

User Action → Control Event → Controller Method

## Basic Rule (IMPORTANT)

- **Events are declared in the View**
- **Event logic is written in the Controller**
- Never write logic in the XML
- Never access DOM directly

## Most Common Control Events

| Control    | Event                | Trigger                    |
| ---------- | -------------------- | -------------------------- |
| Button     | `press`              | Click / tap                |
| Input      | `change`             | Value changed & focus lost |
| Input      | `liveChange`         | Every keystroke            |
| Select     | `change`             | Selection changed          |
| List       | `itemPress`          | List item clicked          |
| Table      | `rowSelectionChange` | Row selected               |
| CheckBox   | `select`             | Checked/unchecked          |
| Switch     | `change`             | Switched on/off            |
| DatePicker | `change`             | Date changed               |

## Button Event Handling

### STEP 1: XML View

**Main.view.xml**

```xml
<Button
  text="Show Minerals"
  press="onShowMinerals" />
```

`onShowMinerals` = function name in controller

### STEP 2: Controller

**Main.controller.js**

```jsx
sap.ui.define(["sap/ui/core/mvc/Controller"], function (Controller) {
  "use strict";

  return Controller.extend("my.app.controller.Main", {
    onShowMinerals: function () {
      sap.m.MessageToast.show("Button pressed!");
    },
  });
});
```

Button click → toast appears

## Getting Control & Model Data in Events

### 1. Get Control That Fired Event

```jsx
var oInput = oEvent.getSource();
```

### 2. Get Model Data

```jsx
var oModel = this.getView().getModel("minerals");
var oData = oModel.getData();
```

## List Item Events

XML

```xml
<List
  items="{minerals>/minerals}"
  itemPress="onItemPress"
  mode="SingleSelectMaster">

  <StandardListItem
    title="{minerals>name}"
    type="Active" />
</List>

```

Controller

```jsx
onItemPress: function (oEvent) {
  var oItem = oEvent.getParameter("listItem");
  var oContext = oItem.getBindingContext("minerals");
  var oObject = oContext.getObject();

  console.log(oObject);
}

```

## Checkbox / Switch Events

Checkbox

```xml
<CheckBox
  text="Available"
  select="onAvailableSelect" />

```

```jsx
onAvailableSelect: function (oEvent) {
  var bSelected = oEvent.getParameter("selected");
  console.log(bSelected);
}

```

## Switch

```xml
<Switch change="onSwitchChange" />

```

```jsx
onSwitchChange: function (oEvent) {
  var bState = oEvent.getParameter("state");
}

```

## Event Parameters

Every event gives you data:

```jsx
oEvent.getSource(); // Control
oEvent.getParameters(); // All event data
oEvent.getParameter("value"); // Specific value
```
